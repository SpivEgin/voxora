# Skills: Telecommunications & Software Engineering

## Voice over IP (VoIP)
- **Protocols**: SIP v2.0, SDP, RTP/RTCP, WebRTC, STUN, TURN, ICE
- **Codecs**: G.711a/u, G.729, Opus, speex, H.264/VP8 for video
- **Networking**: NAT traversal, QoS (DiffServ, 802.1p), SBC configuration/design
- **Softswitches**: Kamailio, OpenSIPS, FreeSWITCH, Asterisk, Yate
- **Hardware**: IP phones (Yealink, Poly, Cisco), media gateways, SIP trunks

## SMS Gateways
- **Protocols**: SMPP (v3.4/v5.0), HTTP REST APIs, SMTP‑to‑SMS
- **Routing**: Long codes, short codes, toll‑free, alphabetic sender IDs, mobile number portability databases
- **Delivery**: DLR (DELIVRD/EXPIRED/REJECTD etc.), concatenation (SAR/UDH), GSM‑7/UCS‑2 encoding
- **Architecture**: Message queues (RabbitMQ/NATS), rate limiting, retry logic, failover providers
- **Integrations**: Webhooks, REST APIs for CRM/Helpdesk (Zoho, Salesforce, Zendesk)

## PBX Systems
- **On‑premise**: FreeSWITCH (Lua/JavaScript dialplan, ESL), Asterisk (dialplan, AMI/AGI), 3CX
- **Cloud/Hosted**: Twilio, Plivo, Voximplant, SignalWire
- **Features**: IVR (VoiceXML, CCXML), queues, ring groups, conference, voicemail‑to‑email, call recording
- **Administration**: CDR/CDR adapters (ODBC, PostgreSQL), real‑time monitoring via WebSocket/SNMP
- **Security**: TLS/SRTP, fail2ban, IPTables, SIP over VPN, digest authentication

## POTS to VoIP Integration
- **Hardware**: Grandstream HT801/HT802, Cisco SPA112/122, AudioCodes MP‑1xx, Sangoma Vega 50/60/100
- **Interfaces**: FXS (connects to analog phone), FXO (connects to PSTN line), T1/E1 PRI/BRI
- **Signal Handling**: Call progress tones (dial tone, ringback, busy, reorder), DTMF relay (RFC 2833, SIP INFO, in‑band), Caller ID (Bellcore FSK, ETSI FSK, DTMF)
- **Disconnect Supervision**: CPC (calling party control), polarity reversal, open‑loop disconnect
- **Advanced**: Echo cancellation (G.168), Jitter Buffer, T.38 Fax, modem passthrough

## General Telecom Knowledge

- PSTN interfaces: POTS lines, ISDN BRI/PRI, SS7 (basic concepts)
- Billing: Radius accounting, custom rate engines, LCR (least cost routing)
- Compliance: FCC/FTC regulations, GDPR considerations, robocall mitigation (STIR/SHAKEN)
- DevOps: CI/CD (GitHub Actions, GitLab CI), infrastructure as code (Terraform, Ansible) for telecom
